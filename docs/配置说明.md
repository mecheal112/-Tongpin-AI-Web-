# 同频 Tongpin — 配置说明

本文档说明「同频」项目从零到跑起来需要动哪些配置、每个配置项在哪里、改了什么效果。

---

## 1. 配置分布总览

项目是 npm workspaces 单仓双包结构，配置分四层：

| 层次 | 文件 | 作用 |
| --- | --- | --- |
| 环境变量 | `.env`（根目录，从 `.env.example` 复制） | 端口、密钥、数据库路径、AI 接入 |
| 根工作区 | `package.json` | 脚本编排、Node 版本要求、workspaces 声明 |
| 后端 | `server/package.json`、`server/src/config.js` | 运行时依赖；环境变量的解析与默认值 |
| 前端 | `web/package.json`、`web/vite.config.ts`、`web/tsconfig.json` | 构建、开发代理、路径别名、TS 规则 |
| 编辑器 | `.vscode/*.json` | 调试配置、任务、推荐插件、格式化规则 |

> 关键约定：**所有环境变量只有根目录一个 `.env`**。`server/src/config.js:10` 用 `dotenv` 显式加载 `ROOT_DIR/.env`（`ROOT_DIR` = `server/src` 上溯两级），不受启动时工作目录影响。

## 2. 环境变量（`.env`）

### 2.1 如何开始

```bash
cp .env.example .env      # Windows: copy .env.example .env
```

**所有项都有内置默认值，完全不配置也能完整运行。** 最小可用配置就是一个空 `.env`。

### 2.2 服务与安全

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `8787` | 后端 HTTP + Socket.IO 监听端口 |
| `NODE_ENV` | `development` | `production` 时启用静态缓存 7 天、关闭 morgan 日志 |
| `JWT_SECRET` | `tongpin-dev-secret-change-me` | 登录令牌签名密钥。**生产必须换成随机长字符串**，否则任何人都能伪造令牌 |
| `JWT_EXPIRES_IN` | `7d` | 令牌有效期，接受 `jsonwebtoken` 的时长写法 |
| `DB_PATH` | `data/tongpin.db` | SQLite 文件位置。相对路径按项目根目录解析，也可写绝对路径 |
| `CORS_ORIGIN` | `http://localhost:5173` | 允许跨域的前端来源，**逗号分隔可填多个** |

生成强密钥：`node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"`

### 2.3 AI 大模型接入

这是本项目唯一「可选但影响体验」的配置。**不配置时不会报错，也不会关闭功能**——系统自动使用内置的本地语义引擎，画像访谈走规则引导版、匹配与破冰走本地算法版，评审演示完全不依赖外部网络。

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `AI_PROVIDER` | 空 → `local` | `anthropic` / `openai`，留空即用本地引擎 |
| `AI_TIMEOUT_MS` | `45000` | 单次模型调用超时（毫秒），超时视为失败 |
| `AI_FALLBACK` | `true` | 远端调用失败/超时时是否自动降级到本地引擎 |

**方案 A — Anthropic Claude**

```dotenv
AI_PROVIDER=anthropic
ANTHROPIC_API_KEY=sk-ant-xxxxxxxx
ANTHROPIC_BASE_URL=https://api.anthropic.com   # 可指向自建代理
AI_MODEL=claude-sonnet-5                        # 主模型，可留空用内置默认
AI_MODEL_FAST=claude-haiku-4-5-20251001         # 轻量任务模型
```

**方案 B — 任意 OpenAI 兼容服务**

```dotenv
AI_PROVIDER=openai
OPENAI_API_KEY=sk-xxxxxxxx
OPENAI_BASE_URL=https://api.deepseek.com/v1     # DeepSeek / 通义 / 月之暗面 / 智谱 / 本地 Ollama
AI_MODEL=deepseek-chat
AI_MODEL_FAST=deepseek-chat
```

两点容易踩坑的地方：

- **`AI_MODEL` 与 `AI_MODEL_FAST` 互不干扰。** 只设 `AI_MODEL` 不会把快速任务路径也顶成昂贵模型（见 `server/src/ai/provider.js:101`）。若都不设，按 `server/src/config.js:67` 的 `DEFAULT_MODELS` 取默认值。
- **`AI_PROVIDER=openai` 但没有 `OPENAI_API_KEY`** 等同于未配置，会静默走本地引擎。可用 `GET /api/health` 的 `ai` 字段确认真实生效状态。

### 2.4 演示数据

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `SEED_DEMO` | `true` | `seed` / `reset` 时创建评审体验账号（统一密码 `Tongpin@2026`） |

## 3. 命令与脚本

根目录 `package.json` 提供统一入口，无需进入子目录：

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 并行启动后端 + 前端（concurrently，青色/品红分色输出） |
| `npm run dev:server` | 仅后端，`node --watch` 热重载 |
| `npm run dev:web` | 仅前端 Vite 开发服务器 |
| `npm run reset` | **清空数据库并重建**种子数据（23 位体验用户、动态、同频局） |
| `npm run seed` | 仅当数据库为空时灌入数据，不清空已有内容 |
| `npm run build` | 前端类型检查 + 打包到 `web/dist` |
| `npm run start` | 生产模式启动后端（托管 `web/dist`） |
| `npm run typecheck` | 前端 `vue-tsc --noEmit` 类型检查 |

运行时要求 **Node >= 22.5.0**（`package.json` 的 `engines`，代码使用了内置 `fetch`、`node --watch`、`node:sqlite` 等能力）。

## 4. 开发与生产两种形态

### 开发模式

```
浏览器 :5173 (Vite)
    ├── /api/*       → 代理到 :8787
    └── /socket.io/* → 代理到 :8787 (ws: true)
```

代理配置见 `web/vite.config.ts:14`，用于规避跨域。此时 `CORS_ORIGIN` 需与 Vite 端口一致。

### 生产模式

```bash
npm run build     # 产出 web/dist
NODE_ENV=production npm run start
```

后端检测到 `web/dist` 存在会直接静态托管，并对非 `/api`、非 `/socket.io` 的路径做 SPA 回退（`server/src/index.js:69-78`）。此时前后端同源，**不再需要 Vite 代理，也不需要配置 `CORS_ORIGIN`**。

> 注意：先跑过 `npm run build` 再启动后端，启动日志里才会出现「已挂载前端构建产物」；否则开放 8787 端口只能访问到 API。

## 5. 前端工程配置

**路径别名**：`@` → `web/src`。在 `vite.config.ts:10` 与 `tsconfig.json` 的 `paths` 中**两处都要配置且保持一致**，Vite 负责运行时分发、TS 负责类型解析，缺一会导致 IDE 报红或构建失败。

**TypeScript 严格模式**：`strict: true`、`noFallthroughCasesInSwitch: true`、`verbatimModuleSyntax: true`。最后一项要求类型导入必须写 `import type { ... }`，是新代码最容易触发的编译错误。

**构建产物**：输出 `web/dist`，`emptyOutDir: true`（每次构建清空），`chunkSizeWarningLimit: 900`。

## 6. 编辑器配置（`.vscode/`）

- **`launch.json`** — 调试组「同频」，含后端、前端、Chrome 三个配置及一个 compound 一键同启。后端调试自动读取根目录 `.env`，并开启 `restart: true`（改代码自动重启）。
- **`tasks.json`** — 常用任务（安装依赖、`reset`、`seed`、`build`、`typecheck`、启动前后端），`Ctrl+Shift+B` 可调出构建组。
- **`settings.json`** — TS 使用工作区自带的 `typescript`（`typescript.tsdk` 指向 `node_modules/typescript/lib`）；缩进 2 空格、标尺 110 列、保存不自动格式化；`.vue` 用 Volar 格式化，`.ts`/`.json` 用 Prettier。
- **`extensions.json`** — 推荐 Volar、ESLint、Prettier 等插件。**用 Vue 项目务必安装 Volar，且禁用内置 Vetur**，否则 `.vue` 文件类型会错乱。

---

## 7. 被忽略的文件（`.gitignore`）

`node_modules/`、`dist/`、`.env`、`data/*.db*`（含 `-wal` / `-shm`）、日志、`.vite/`、`coverage/`。

含义很明确：**数据库是本地运行产物，不入库**。团队成员拿到代码后需自行执行 `npm run reset` 生成自己的数据副本。同理 `.env` 不入库，新成员从 `.env.example` 复制。

## 8. 配置检查清单

首次跑起来 / 部署前逐条确认：

- [ ] `npm install` 成功，Node 版本 >= 22.5.0
- [ ] 已从 `.env.example` 复制出 `.env`
- [ ] 生产环境已替换 `JWT_SECRET` 为随机长字符串
- [ ] `npm run reset` 已执行，`data/tongpin.db` 存在
- [ ] 访问 `GET /api/health`，`ok: true`，`ai` 字段符合预期
- [ ] 若填了 AI Key：`ai.configured` 为 `true`，否则会静默走本地引擎
- [ ] 前后端分离部署时 `CORS_ORIGIN` 已改为真实前端域名（多个用逗号分隔）
- [ ] 生产部署前已执行 `npm run build`，否则后端只有 API 没有页面
